# Lucie Framework

Lucie is a modern and flexible game framework written in Zig.

## Features (Planned)

*   Cross-platform support
*   Efficient 2D/3D rendering (OpenGL, Vulkan planned)
*   Integrated Entity Component System (ECS)
*   Physics engine
*   Audio system
*   UI tools
*   And more!
